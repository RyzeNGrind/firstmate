=== CHANGE SUMMARY ===
The fix changes the --contribution-input code path from using --argjson (which
passes JSON via shell argv) to --slurpfile (which reads JSON from temp files).

File: bin/fm-fleet-snapshot.sh
Lines 2004-2005:
  jq -n --slurpfile backlog "$BACKLOG_JSON_FILE" --slurpfile tasks "$JSON_TRANSPORT_DIR/contribution-tasks.json" \
    '{backlog:$backlog[0],tasks:$tasks[0]}'

This solves the "Argument list too long" error when the backlog JSON exceeds
the kernel's per-argument limit (typically ~128KB on Linux).
